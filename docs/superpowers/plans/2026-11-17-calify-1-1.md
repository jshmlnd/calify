# Calify 1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Calify 1.1.0. It drops Spotify/CSV, removes single files, saves battery, and adds a changelog, bug reports, Google accounts, profiles, self-updating, and host-led Listen together.

**Architecture:**
- **Same app shape:** one React/Vite app shipped through Electron (Windows) and Capacitor (Android).
- **Supabase** (Postgres + RLS, Auth, Storage, Realtime, one Edge Function) backs accounts, profiles, bug reports and Listen together signaling/chat.
- **Listen together audio:** a WebRTC mesh from the host's `<audio>.captureStream()` to each listener, with Cloudflare TURN as the fallback relay.
- **Pure, testable logic** lives in small modules: pruning, theme, codes and rules, version compare. The UI wires them into the existing components.

**Tech Stack:**
- Already used: React 19, zustand persist, Vite 8, Electron (stock, from npm), electron-builder NSIS, Capacitor 8, `node --test`.
- New: `@supabase/supabase-js` v2, `electron-updater`.
- Tooling: Supabase CLI via `npx supabase`; Cloudflare `wrangler` (installed); GitHub `gh` (installed).

**Spec:** `docs/superpowers/specs/2026-11-17-calify-1-1-design.md`

## Global Constraints

**Version and signing**
- Version **1.1.0** everywhere: `package.json` `version`, Android `versionName "1.1.0"`, `versionCode 2`, About text, changelog head.
- Android release and debug APKs are signed with this PC's debug keystore `C:\Users\Administrator.JOSHUAA\.android\debug.keystore`. No new keystore.

**Secrets and data**
- Only `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` may be in the app (`.env`, git-ignored).
- These never appear in the app or git: Cloudflare token, Supabase service key, GitHub token.
- Music files never leave the device. Images uploaded are only: profile photo, background, public-playlist cover, last-played art. Each is resized to ≤ 1024 px, WebP.
- Local playback works signed out and offline. With no Supabase env, social features hide instead of crashing.
- 1.0 data survives: local files, Calify playlists, Liked Songs, settings. Only `source: 'spotify'` (and earlier `audius`) entries are dropped.

**Sign-in**
- Google only. OAuth redirects: desktop `http://127.0.0.1:43821/callback`; Android `calify://auth`.

**Listen together**
- Code `CALI-` + 4 digits (`/^CALI-\d{4}$/`). Max **5** members incl. host.
- Join requests time out after **60 s**.
- Join link `https://calify.zjkm.tech/calify/join?c=CALI-0000`; privacy page `https://calify.zjkm.tech/calify/privacy`.
- Chat message max **500** characters, not persisted.

**Themes and accent**
- Themes `calico` (default), `midnight`, `daylight`.
- Accent presets (8, ginger first): `#f08a3c #e8115b #1ed760 #509bf5 #8d67ab #f2b33d #e91429 #14b8a6`.

**Updates and dependencies**
- Releases are published to GitHub Releases of `jshmlnd/calify`.
- No new runtime dependencies beyond `@supabase/supabase-js` and `electron-updater`.

**Owner-only steps** (marked **OWNER** below): the agent stops and asks; it never creates accounts or enters passwords.

## Review Focus

1. **Removing a local file that's playing, queued, or in the current context.** Playback continues or stops cleanly; queue order indexes stay valid; liked, playlists and history no longer show it. Test in Task 2.
2. **A listener presses Space, media keys or keyboard shortcuts.** Nothing changes on the host; the listener sees "Only the host controls playback". Test in Task 11.
3. **The host disappears.** It quits, crashes or loses network. Listeners see "The session ended" within 15 s instead of hanging. Test in Task 11.
4. **Messy code input:** `cali 0482`, `0482`, a full join URL, an unknown code, a full session, a denied request, a 60 s timeout. Each gets a specific message. Tests in Tasks 10–11.
5. **Startup offline or signed out, after picking a non-default theme.** The last saved theme/accent applies from local storage; no network errors are shown. Test in Task 6.
